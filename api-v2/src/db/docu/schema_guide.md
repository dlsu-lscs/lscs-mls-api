## 1. Change Log

### 2026-11-11 — `user_preferences` table (Feature: User Preference)

**Branch:** `feature/41-UserPreference`

New table storing a user's onboarding preferences. One row per user, linked to
`users` via a foreign key with `ON DELETE CASCADE` — deleting a user also deletes
their preferences.

| Column | Type | Constraints | Notes |
|--------|------|-------------|-------|
| `uid` | `INTEGER` | `PRIMARY KEY`, FK → `users(uid)` `ON DELETE CASCADE` | Same value as the user's `uid` |
| `preferred_times` | `JSONB` | `DEFAULT '[]'::jsonb` | Array of time-preference strings, e.g. `["08:00-10:00"]` |
| `preferred_f2f` | `JSONB` | `DEFAULT '[]'::jsonb` | Array of face-to-face preference strings |
| `preferred_free` | `JSONB` | `DEFAULT '[]'::jsonb` | Array of free-time preference strings |
| `target_units` | `INTEGER` | nullable | Target number of units the user wants |
| `program_code` | `VARCHAR(50)` | nullable | User's program code |
| `college` | `VARCHAR(100)` | nullable | User's college |
| `max_vacant` | `INTEGER` | nullable | Maximum vacant units the user is willing to take |
| `preferred_campus` | `VARCHAR(80)` | nullable | Preferred campus |

**DDL:**

```sql
CREATE TABLE IF NOT EXISTS user_preferences (
    uid INTEGER PRIMARY KEY,
    preferred_times JSONB DEFAULT '[]'::jsonb,
    preferred_f2f JSONB DEFAULT '[]'::jsonb,
    preferred_free JSONB DEFAULT '[]'::jsonb,
    target_units INTEGER,
    program_code VARCHAR(50),
    college VARCHAR(100),
    max_vacant INTEGER,
    preferred_campus VARCHAR(80),
    FOREIGN KEY (uid)
        REFERENCES users(uid)
        ON DELETE CASCADE
);
```

**Drizzle schema:** `src/db/schema/user_preferences.schema.ts`

```ts
import { pgTable, integer, varchar, jsonb } from "drizzle-orm/pg-core";
import { users } from "./users.schema.js";

export const userPreferences = pgTable("user_preferences", {
  uid: integer("uid")
    .primaryKey()
    .references(() => users.uid, { onDelete: "cascade" }),

  preferredTimes: jsonb("preferred_times").$type<string[]>().default([]),
  preferredF2f: jsonb("preferred_f2f").$type<string[]>().default([]),
  preferredFree: jsonb("preferred_free").$type<string[]>().default([]),
  targetUnits: integer("target_units"),
  programCode: varchar("program_code", { length: 50 }),
  college: varchar("college", { length: 100 }),
  maxVacant: integer("max_vacant"),
  preferredCampus: varchar("preferred_campus", { length: 80 }),
});
```

## 3. Applying Schema Changes

```bash
cd api-v2
# Generate migration files from Drizzle schemas
npx drizzle-kit generate
# Apply pending migrations to the database
npx drizzle-kit migrate
```

> `PostgreSQL-Translated.sql` is the human-readable DDL reference. For actual
> migrations, prefer `drizzle-kit generate` so the migration history is tracked
> in `drizzle/meta/`.
